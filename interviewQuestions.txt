## Question 01 — Delete Nth Node From End of Linked List

Given the head of a linked list, remove the nth node from the end of the list and return its head.

### Example 1
Input:  head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]

### Example 2
Input:  head = [1], n = 1
Output: []

### Example 3
Input:  head = [1,2], n = 1
Output: [1]

## Question 02 — Move Zeros to End

Given an integer array nums, move all 0's to the end while maintaining the relative order of non-zero elements.

Do it in-place without creating another array.

### Example 1
Input:  nums = [0,1,0,3,12]
Output: [1,3,12,0,0]

### Example 2
Input:  nums = [0]
Output: [0]
